# Mini Dashboard

## But du projet
Ce projet présente un mini tableau de bord personnel avec quelques cartes utiles pour montrer une interface moderne et organisée. Il reste volontairement simple tout en donnant un rendu propre pour un portfolio.

## Fonctionnalités
- carte de bienvenue
- affichage de la date du jour
- carte avec des tâches rapides
- carte avec une statistique de progression fictive
- bouton pour basculer entre thème clair et sombre
- sauvegarde du thème choisi dans le localStorage
- design responsive et sobre

## Technologies utilisées
- HTML
- CSS
- JavaScript vanilla

## Comment lancer le projet
1. Ouvrir le dossier `projet-mini-dashboard` dans VS Code.
2. Ouvrir le fichier `index.html` dans le navigateur.
3. Changer le thème pour vérifier la sauvegarde locale.
